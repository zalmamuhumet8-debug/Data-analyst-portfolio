# Power BI Sales Dashboard

## Overview
An interactive sales dashboard built with Microsoft Power BI to analyze sales performance and identify business trends.

## Objectives
- Analyze total sales performance
- Compare sales by product
- Analyze sales by city
- Identify customer sales performance
- Provide interactive filters for business insights

## Tools
- Microsoft Power BI
- Power Query
- DAX
- Excel / CSV

## Dashboard Features
- Total Sales KPI
- Total Orders KPI
- Average Sales KPI
- Sales by Product
- Sales by City
- Customer Sales Analysis
- Interactive Slicers

## Key Insights
The dashboard helps identify top-performing products, cities, and customers and provides an overview of overall sales performance.
