# Sales Data Analysis

## Project Overview
This project analyzes sales data using Python and Pandas.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Dataset
The dataset contains:
- Order ID
- Date
- Product
- Category
- Quantity
- Price
- Sales
- Region

## Analysis Performed
- Data exploration
- Summary statistics
- Missing value check
- Sales by Region
- Sales by Category
- Top-selling Products

## Key Insights
- Compared total sales across regions.
- Identified the best-selling product.
- Analyzed sales by product category.
